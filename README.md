# VertaPro · mídias e publicador

Arquivos de divulgação do VertaPro (imagens e vídeos) e o programa que publica no Instagram (@vertaprogestaofinanceira) nos dias e horários de `agenda.json`.
Fica público porque a Meta precisa buscar cada arquivo por um endereço aberto na internet. Não há senhas aqui: o token do Instagram fica guardado como segredo do GitHub.
